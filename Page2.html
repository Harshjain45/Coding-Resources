Introduction to C++

C++ is a powerful general-purpose programming language developed by Bjarne Stroustrup in the early 1980s.

Features of C++

  • Object-Oriented Programming (OOP)
  • Rich Standard Library
  • High Performance
  • Portability
  • Compatibility with C

Basic Syntax

#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
  • #include <iostream> includes the input/output library.
  • using namespace std; allows use of standard library features.
  • int main() is the entry point of the program.
  • cout is used for output.
  • return 0; indicates successful execution.
